Set your delay and reverb to 130 BPM

The most common reason to need these numbers is a tempo-locked delay. A delay set to an exact note value stays glued to the rhythm; a delay set to an arbitrary number slowly drifts out of time. At 130 BPM:

  • Dotted eighth (346.15 ms) — the classic choice; falls between beats and fills gaps without clutter.
  • Eighth (230.77 ms) — tighter, doubles the repeat density.
  • Quarter (461.54 ms) — clear repeats sitting on every beat.
  • Bar (1846.15 ms, 4/4) — a slow, spacious echo.

Frequently asked questions

How do you convert 130 BPM to milliseconds?
One beat lasts 60,000 ÷ 130 ≈ 461.54 ms. Every other note value scales from that single number: a half note is twice the beat, an eighth note is half, a sixteenth is a quarter, and so on.
What is one beat (a quarter note) in milliseconds at 130 BPM?
At 130 BPM a quarter note — one beat — is 461.54 ms. That is the anchor for every delay, reverb pre-delay and sequencer step at this tempo.
What delay time matches 130 BPM?
The classic choice is a dotted eighth note, which lands between beats and fills the gaps without cluttering the groove. At 130 BPM an eighth note is 230.77 ms, so a dotted eighth is 346.15 ms. A straight eighth (230.77 ms) doubles the repeat density; a quarter note (461.54 ms) sits on every beat.
How long is one bar at 130 BPM in 4/4?
A bar of 4/4 holds four beats, so at 130 BPM it lasts about 1846.15 ms. For other time signatures multiply the quarter-note length by the number of beats per bar.

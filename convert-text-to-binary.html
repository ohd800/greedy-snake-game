How text becomes binary

Computers store text as bytes. This tool encodes your text with UTF-8, the dominant encoding on the web, then prints each byte as 8 binary digits.

Worked example. The letter H is code point U+0048, which is 72 in decimal. In UTF-8 it fits in a single byte:

72 → 01001000

The string Hi therefore becomes:

01001000 01101001

Characters outside ASCII need more than one byte, which is where many simple converters break:

Frequently asked questions

Why does one character sometimes produce several bytes of binary?
This tool encodes text as UTF-8, the standard encoding on the web. Basic English letters use one byte, accented characters such as é use two, and emoji use four. Tools that emit a fixed 8 bits per character cannot represent emoji correctly.
Can I convert binary back to text?
Yes. Paste a binary string into the lower box and the decoded text appears immediately. Spaces between bytes are optional.
Is my text uploaded anywhere?
No. Encoding and decoding happen entirely in your browser; nothing you type is sent to a server.
Why is my binary output different from another converter?
Other tools may use 16-bit Unicode units or Latin-1 instead of UTF-8. That is fine for plain English but produces different — and usually undecodable — results for emoji and accented characters.

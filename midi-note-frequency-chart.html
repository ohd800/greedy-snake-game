How MIDI numbers work

MIDI note numbers are simply a linear count of semitones. Each step of 1 is one semitone, so each step of 12 is one octave. Three anchors are worth memorising:

  • MIDI 60 = C4 — middle C, 261.63 Hz.
  • MIDI 69 = A4 — the tuning reference, 440.00 Hz.
  • MIDI 21 = A0 — the lowest note on an 88-key piano, 27.50 Hz.

The full range runs from MIDI 0 (C−1, 8.18 Hz) to MIDI 127 (G9, 12543.85 Hz). An ordinary 88-key piano only uses 21 to 108 of these, which is why the piano note frequency chart is a subset of this table.

The formula

To turn a MIDI number m into a frequency:

f = 440 × 2(m − 69) / 12

and to go back the other way:

m = 69 + 12 × log2(f / 440)

Rounding m to the nearest whole number gives you the closest MIDI note for any frequency, which is what the converter does when you type in hertz.

A note on octave numbering

MIDI numbers are unambiguous, but the names beside them are not universal. This table uses scientific pitch notation, in which middle C is C4 and A4 is 440 Hz. Yamaha and some DAWs call middle C “C3” instead — same key, same frequency, different label. When in doubt, quote the MIDI number. See middle C frequency for the full explanation.

Frequently asked questions

What MIDI number is A4?
A4 is MIDI note 69, at 440 Hz. It is the anchor for the whole system: the formula f = 440 × 2^((m − 69) / 12) is built around it.
What MIDI number is middle C?
Middle C is MIDI note 60 (C4), at 261.63 Hz. Some manufacturers label this C3, but the MIDI number is always 60.
What is the range of MIDI note numbers?
MIDI note numbers run from 0 to 127 — C−1 (8.18 Hz) to G9 (12543.85 Hz). A standard 88-key piano covers only 21 (A0) to 108 (C8).
How do you convert a MIDI number to hertz?
Use f = 440 × 2^((m − 69) / 12). For example MIDI 60 gives 440 × 2^((60 − 69) / 12) = 261.63 Hz.
How do you convert hertz to a MIDI number?
Use m = 69 + 12 × log2(f / 440), then round to the nearest whole number. 440 Hz gives exactly 69; 261.63 Hz gives 60.
Do all MIDI instruments use the same frequencies?
The nominal mapping is the same, but tuning is not. Orchestras may tune to 442 or 443 Hz, some historical ensembles use 415 Hz, and the numbers here assume the equal-tempered 440 Hz default.

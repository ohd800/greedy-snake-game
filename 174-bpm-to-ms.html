Set your delay and reverb to 174 BPM

The most common reason to need these numbers is a tempo-locked delay. A delay set to an exact note value stays glued to the rhythm; a delay set to an arbitrary number slowly drifts out of time. At 174 BPM:

  • Dotted eighth (258.62 ms) — the classic choice; falls between beats and fills gaps without clutter.
  • Eighth (172.41 ms) — tighter, doubles the repeat density.
  • Quarter (344.83 ms) — clear repeats sitting on every beat.
  • Bar (1379.31 ms, 4/4) — a slow, spacious echo.

Frequently asked questions

How do you convert 174 BPM to milliseconds?
One beat lasts 60,000 ÷ 174 ≈ 344.83 ms. Every other note value scales from that single number: a half note is twice the beat, an eighth note is half, a sixteenth is a quarter, and so on.
What is one beat (a quarter note) in milliseconds at 174 BPM?
At 174 BPM a quarter note — one beat — is 344.83 ms. That is the anchor for every delay, reverb pre-delay and sequencer step at this tempo.
What delay time matches 174 BPM?
The classic choice is a dotted eighth note, which lands between beats and fills the gaps without cluttering the groove. At 174 BPM an eighth note is 172.41 ms, so a dotted eighth is 258.62 ms. A straight eighth (172.41 ms) doubles the repeat density; a quarter note (344.83 ms) sits on every beat.
How long is one bar at 174 BPM in 4/4?
A bar of 4/4 holds four beats, so at 174 BPM it lasts about 1379.31 ms. For other time signatures multiply the quarter-note length by the number of beats per bar.

How BPM converts to milliseconds

There are 60,000 milliseconds in a minute, so one beat lasts:

milliseconds per beat = 60000 ÷ BPM

Worked example. At 120 BPM:

60000 ÷ 120 = 500 ms per quarter note

Everything else scales from that one number:

  • Eighth note = half a beat → 500 ÷ 2 = 250 ms
  • Sixteenth note = a quarter of a beat → 500 ÷ 4 = 125 ms
  • Dotted = 1.5× the straight value → dotted eighth 250 × 1.5 = 375 ms
  • Triplet = ⅔ of the straight value → eighth triplet 250 × ⅔ = 166.67 ms

Choosing a delay time

Delay is the most common reason to need these numbers. A delay set to an exact note value stays locked to the groove; a delay set to an arbitrary number slowly drifts out of time.

Frequently asked questions

How do you convert BPM to milliseconds?
One beat lasts 60,000 divided by the BPM, in milliseconds. At 120 BPM that is 60000 / 120 = 500 ms per beat. Other note lengths scale from there: an eighth note is half a beat, a sixteenth note is a quarter of a beat.
How do I set a delay to match the tempo?
Enter the track tempo and read off the note value you want the repeats to land on. A dotted eighth delay time is a very common choice because it sits between beats and fills the gaps without cluttering the rhythm.
What is a triplet in milliseconds?
A triplet divides a beat into three equal parts instead of two, so each triplet note lasts two thirds of the straight note. At 120 BPM a quarter note is 500 ms, so a quarter-note triplet is 333.33 ms.
Does this work for any time signature?
The note lengths are independent of time signature. The bar length shown assumes 4/4, which is the most common; for other signatures multiply the quarter note length by the number of beats per bar.
Is my data uploaded anywhere?
No. The calculation runs entirely in your browser; nothing is sent to a server.

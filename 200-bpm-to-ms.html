Set your delay and reverb to 200 BPM

The most common reason to need these numbers is a tempo-locked delay. A delay set to an exact note value stays glued to the rhythm; a delay set to an arbitrary number slowly drifts out of time. At 200 BPM:

  • Dotted eighth (225.00 ms) — the classic choice; falls between beats and fills gaps without clutter.
  • Eighth (150.00 ms) — tighter, doubles the repeat density.
  • Quarter (300.00 ms) — clear repeats sitting on every beat.
  • Bar (1200.00 ms, 4/4) — a slow, spacious echo.

Frequently asked questions

How do you convert 200 BPM to milliseconds?
One beat lasts 60,000 ÷ 200 ≈ 300.00 ms. Every other note value scales from that single number: a half note is twice the beat, an eighth note is half, a sixteenth is a quarter, and so on.
What is one beat (a quarter note) in milliseconds at 200 BPM?
At 200 BPM a quarter note — one beat — is 300.00 ms. That is the anchor for every delay, reverb pre-delay and sequencer step at this tempo.
What delay time matches 200 BPM?
The classic choice is a dotted eighth note, which lands between beats and fills the gaps without cluttering the groove. At 200 BPM an eighth note is 150.00 ms, so a dotted eighth is 225.00 ms. A straight eighth (150.00 ms) doubles the repeat density; a quarter note (300.00 ms) sits on every beat.
How long is one bar at 200 BPM in 4/4?
A bar of 4/4 holds four beats, so at 200 BPM it lasts about 1200.00 ms. For other time signatures multiply the quarter-note length by the number of beats per bar.
